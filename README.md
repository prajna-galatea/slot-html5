# 五軸老虎機

這是一款在瀏覽器裡玩的 5×3、20 線老虎機，盤面上只有一個 WILD。

[打開遊戲](https://prajna-galatea.github.io/slot-html5/)

點 START 會開啟聲音，之後就可以玩。

## 怎麼玩

點 SPIN 開始轉。結果鎖定後，按鈕會變成 SKIP；再點一次，還沒停的轉輪會立刻停下。

餘額不足時不能轉。

## 押注

用 − 和 ＋ 調整單線押注。總押注 = 單線押注 × 20。

## 其他按鈕

TURBO：轉輪比較快。

PAYS：看賠付表。點畫面外面，或點「點擊關閉」，就能關掉。

斷線：測試用。按了之後，下一手可能會假裝斷線。如果結果已經鎖定，重新整理頁面就能接回那一手。
